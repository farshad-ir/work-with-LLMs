# قرارداد JSON — CONSULT-LLM (V1)

### هدف
ارسال پرسش به مدل زبانی از طریق MT5. امکان استخراج داده از SQLite و ارسال آن همراه پرسش به مدل وجود دارد.

### ساختار درخواست

**۱. همراه با استخراج داده از SQLite:**

```json
{
  "command": "CONSULT-LLM",
  "select": {
    "type": "SELA",
    "table": "candles",
    "columns": ["*"],
    "limit": 30
  },
  "inquiry": {
    "question": "آیا جهت میانگین تغییر کرده است؟"
  }
}
```

**۲. بدون استخراج داده:**

```json
{
  "command": "CONSULT-LLM",
  "inquiry": {
    "question": "تفاوت میانگین متحرک ساده و نمایی چیست؟"
  }
}
```

### مشخصات فیلدها

| فیلد | وضعیت | توضیح |
|---|---|---|
| `command` | اجباری | مقدار ثابت `CONSULT-LLM` |
| `select` | اختیاری | درخواست استخراج داده از SQLite |
| `select.type` | اجباری در صورت وجود select | فعلاً فقط `SELA` |
| `select.table` | اجباری | نام جدول |
| `select.columns` | اجباری | آرایه نام ستون‌ها |
| `select.limit` | اختیاری | حداکثر تعداد رکوردها |
| `inquiry` | اجباری | بخش پرسش از مدل |
| `inquiry.question` | اجباری | متن پرسش |

### قواعد اجرا

1. ابتدا درخواست اعتبارسنجی می‌شود.
2. در صورت وجود `select`، دستور `SELA` اجرا می‌شود.
3. رکوردهای استخراج‌شده همراه پرسش به مدل زبانی ارسال می‌شوند.
4. در صورت نبود `select`، فقط پرسش به مدل ارسال می‌شود.
5. ترتیب داده‌های ارسالی به مدل باید **از قدیمی‌ترین رکورد به جدیدترین رکورد** باشد.
6. اجرای درخواست MT5 با شناسه مصرف‌کننده `mt5` انجام می‌شود.

**نکته:** در V1 تنها عملیات استخراج `SELA` پشتیبانی می‌شود. این قرارداد در نسخه‌های بعدی قابلیت توسعه دارد.
