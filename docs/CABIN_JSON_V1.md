# Approved Decision — commands.json

## 1. تصمیم معماری

ساختار فعلی JSON تصویب شد.

فیلد جدیدی مانند `destination` اضافه نمی‌شود. نام فرمان برای تشخیص مسئول پردازش کافی است.

سه نوع فرمان فعلی:

- `CONSULT-LLM`
- `CHART-INIT`
- `MT5-RESEND`

## 2. قانون تشخیص در متاتریدر

متاتریدر هنگام خواندن `commands.json` فقط نام فرمان را بررسی می‌کند:

- اگر `command` برابر `MT5-RESEND` باشد، فرمان را برای خودش برمی‌دارد و اجرا می‌کند.
- در تمام موارد دیگر، کل JSON را بدون تفسیر محتوای فرمان، بسته‌بندی کرده و برای Python می‌فرستد.

بنابراین `CONSULT-LLM` و `CHART-INIT` هر دو به Python ارسال می‌شوند.

## 3. نمونه اول: درخواست مدل زبانی

```json
{
    "commands": [
        {
            "command": "CONSULT-LLM",
            "select": {
                "type": "SELA",
                "table": "h1Candles",
                "columns": ["*"],
                "limit": 60
            },
            "inquiry": {
                "question": "Analyze the Mabif river across these 60 candles."
            },
            "status": ""
        }
    ]
}
```

یا بدون سکلت

```json
{
    "commands": [
        {
            "command": "CONSULT-LLM",
            "inquiry": {
                "question": "Analyze the current market context and explain the most important observations."
            },
            "status": ""
        }
    ]
}
```

**رفتار:** متاتریدر JSON را بسته‌بندی و برای Python ارسال می‌کند. Python عملیات را انجام می‌دهد و درخواست را برای مدل زبانی آماده می‌کند.

## 4. نمونه دوم: آماده‌سازی محدوده کندل‌ها

```json
{
    "commands": [
        {
            "command": "MT5-RESEND",
            "operation": "TAKE-DATES",
            "start": "2026.01.01 00:00",
            "end": "2026.03.01 00:00",
            "status": ""
        }
    ]
}
```

**رفتار:** متاتریدر JSON را بررسی می کند.


## 5. نمونه سوم: ارسال کندل بعدی

```json
{
    "commands": [
        {
            "command": "MT5-RESEND",
            "operation": "SEND-NEXT",
            "status": ""
        }
    ]
}
```

**رفتار:** متاتریدر فرمان را برای خودش برمی‌دارد و اجرا می‌کند. کندل بعدی را استخراج و ارسال می‌کند و موقعیت آخرین کندل ارسال‌شده را در حافظه موقت اکسپرت به‌روزرسانی می‌کند.

## 6. نمونه جهارم: ارسال دستور درخواست لیست جدولها: این دستور اینگونه نوشته می شود ولی همراه  CHART-INIT ارسال می شود

```json
{
    "commands": [
        {
            "command": "LIST-TABL",
            "status": ""
        }
    ]
}
```

**رفتار:** متاتریدر JSON را به پایتون ارسال می کند


## 6. قواعد ثابت

1. ساختار اصلی `commands` حفظ می‌شود.
2. فیلد `destination` اضافه نمی‌شود.
3. وجود یا نبودن `select` تعیین‌کننده مقصد نیست.
4. فقط `MT5-RESEND` توسط متاتریدر اجرا می‌شود.
5. تمام فرمان‌های دیگر برای Python ارسال می‌شوند.
6. متاتریدر نباید محتوای فرمان‌های مربوط به Python را تفسیر یا تغییر دهد.
7. وضعیت آخرین کندل ارسالی فقط در حافظه موقت اکسپرت نگهداری می‌شود.
